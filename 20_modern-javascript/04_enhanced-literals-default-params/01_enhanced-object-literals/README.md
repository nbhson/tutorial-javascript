# Enhanced Object Literals

## Khái niệm
ES6+: shorthand `{x}` thay vì `{x: x}`, method shorthand `{foo(){}}`, computed key `{[expr]: val}`, getter/setter.

## Điểm mạnh
- Ngắn gọn, dễ đọc
- Tạo config object nhanh

## Khi nào dùng
- Redux reducer action; function return config; event options.

## 📚 Tham khảo
- `app.js`, `index.html`
