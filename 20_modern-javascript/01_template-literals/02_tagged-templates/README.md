# Tagged Templates

## Khái niệm
Gọi function với template literal: `` tag`hello ${name}` ``. Tag nhận `strings` (array) và `...values`.

## Điểm mạnh
- Tạo DSL (HTML/SQL/CSS template engine)
- Escape HTML, internationalization, syntax highlighting

## Khi nào dùng
- Styled Components; SQL query builder; i18n message.

## 📚 Tham khảo
- `app.js`, `index.html`
