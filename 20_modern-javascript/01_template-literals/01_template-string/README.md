# Template String (Template Literals)

## Khái niệm
Dùng backtick `` ` `` thay vì `'` hoặc `"`. Hỗ trợ multi-line, `${expr}` interpolation, tagged template function.

## Điểm mạnh
- Multi-line không cần `\n`
- Expression trực tiếp, không cần `+` nối
- Định dạng dễ đọc (URL, SQL, CSS)

## Khi nào dùng
- HTML template; log message phức tạp; component JSX.

## 📚 Tham khảo
- `app.js`, `index.html`
