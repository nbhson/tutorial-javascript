# Destructuring & Rest

## Khái niệm
Destructuring: lấy giá trị từ array/object gọn: `const {name, age} = user;`, `const [first, ...rest] = arr;`. Rest `...rest` Gom phần còn lại.

## Điểm mạnh
- Gán nhiều biến 1 dòng
- Swap biến `[a, b] = [b, a]`
- Named import trực tiếp

## Khi nào dùng
- API response xử lý; React props; function param extraction.

## 📚 Tham khảo
- `app.js`, `index.html`
