# DOM Manipulation Example 1

## Khái niệm
Thao tác DOM động: `createElement`, `appendChild`, `insertBefore`, `replaceChild`, `removeChild`, `cloneNode`. Có thể di chuyển node từ chỗ này sang chỗ khác.

## Điểm mạnh
- Thêm/xóa/sắp xếp element tùy ý
- Không cần innerHTML → an toàn hơn với XSS
