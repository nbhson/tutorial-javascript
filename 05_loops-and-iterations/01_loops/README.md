# Loops and Iterations

> roadmap.sh: for, do...while, while, for...in, for...of, break/continue

| Loop | Dùng khi |
|---|---|
| `for` | số lần biết trước |
| `while` | điều kiện đầu |
| `do...while` | ít nhất 1 lần |
| `for...in` | keys object |
| `for...of` | values iterable |

Xem `1_for.js` → `7_lap-long-nhau.js` demo từng loại.
