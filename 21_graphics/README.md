# Graphics in JavaScript — Elective

> Nhóm elective — đồ họa 2D/3D trong browser, không nằm trực tiếp trong core roadmap nhưng là skill bổ trợ quan trọng cho frontend developer.

| Mục | Chủ đề | Công nghệ |
|---|---|---|
| **01** | Raster & SVG | `<svg>`, `<image>`, CSS animation |
| **02** | 2D Animation | `requestAnimationFrame`, delta time |
| **03** | SVG Bar Chart | `<rect>`, `<text>`, SVG dynamic |
| **04** | Canvas 2D | `<canvas>`, Context2D API |

## 🔗 Liên quan đến roadmap
- SVG animation liên quan `12_asynchronous-javascript` (requestAnimationFrame)
- Canvas liên quan `18_dom-apis` (DOM manipulation)

## ▶️ Cách học
1. Mở `index.html` trong browser (cần HTTP server)
2. Xem `app.js` để hiểu logic animation/rendering
3. Tự modify code thử nghiệm
