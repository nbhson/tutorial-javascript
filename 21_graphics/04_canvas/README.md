# Canvas 2D

## Khái niệm
`<canvas>` vẽ pixel raster qua Context2D API: `fillRect`, `stroke`, `beginPath/arc`, `drawImage`, `putImageData`.

## Điểm mạnh
- Hiệu năng cao cho 60fps game/complex viz
- Pixel-level control; có thể export image

## Khi nào dùng
- Game, drawing app, image filter, heatmap.

## 📚 Tham khảo
- `index.html` — mở bằng Live Server hoặc browser trực tiếp
