# SVG Bar Chart

## Khái niệm
Vẽ biểu đồ cột bằng SVG: `<rect>` làm cột, `<text>` làm label, `<g>` nhóm, scale tự động theo data.

## Điểm mạnh
- SVG scalable, dễ style qua CSS
- Có thể thêm tooltip/hover bằng JS
- Accessible (title/desc)

## Khi nào dùng
- Dashboard; report; chart đơn giản không cần thư viện.

## 📚 Tham khảo
- `app.js`, `index.html`
