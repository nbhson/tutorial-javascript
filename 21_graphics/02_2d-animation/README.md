# 2D Animation

## Khái niệm
`requestAnimationFrame` chạy callback trước mỗi frame (60fps). Tính delta time để animation mượt bất kể fps màn hình.

## Điểm mạnh
- Hiệu suất cao, tự pause khi tab inactive
- Delta time giữ tốc độ đồng nhất

## Khi nào dùng
- Game 2D; animation UI; particle system; data viz động.

## 📚 Tham khảo
- `app.js`, `index.html`, `style.css`
