# Raster & SVG Clock

## Khái niệm
SVG là vector graphics (XML). Raster là pixel-based (PNG/JPG). SVG không mờ khi zoom, tương tác qua CSS/JS.

## Điểm mạnh
- SVG scalable, crisp on retina
- Có thể animate CSS/JS trực tiếp trên element
- Nhỏ file size cho icon

## Khi nào dùng
- Icon, logo, chart, animation đơn giản.

## 📚 Tham khảo
- `index.html`, `style.css`, `clock.png` (reference)
